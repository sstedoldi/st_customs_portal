- Update task with new version

	1. Rebuild docker into the proper repository
	2. New image is create with a new tag/version
	3. Define a new task version into the proper task family
	4. Change docker image use by the task version
	5. Update service running in the cluster, to the new task version

- Stop task created by service

	Update de service to task = 0
